# Branding

An architectural **R** whose upper lobe is a rounded **Play** wedge (`▶`) and whose diagonal leg is smoked glass (`50%` opacity), set in warm bone `#f2efea` on an obsidian cinema squircle (`#292621` to `#000000`).

- `rstream-icon.svg` / `rstream-icon.png`: desktop & launcher app icon (`1024×1024`).
- `rstream-symbol.svg`: transparent mark.
- `rstream-tv-banner.svg`: Android TV Leanback launcher banner (`640×360` / `320×180 dp`).
- Android adaptive + Material You monochrome launcher resources live in `apps/rstream/android/res/`.
- Windows multi-size icon resource lives in `apps/rstream/windows/rstream.ico` (`rstream.rc`).
